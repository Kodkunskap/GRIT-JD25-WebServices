# RESTServer

En enkel REST-server skriven med JAX-RS (Jakarta / Jersey).

1. Skapa ett nytt Maven Archetype projekt med quickstart-arketypen. 
2. Uppdatera pom.xml med de beroenden som krävs. 
3. Kör programmet via intellij IDEA.
4. Använd webbläsaren eller Postman för att interagera med servicen.
