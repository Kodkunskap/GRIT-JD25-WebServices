# Headers

Några enkla exempel som visar hur man kan arbeta med olika headers i Java-klienter och servrar.

För att skapa eller kod projektet från början gör:

1. Skapa ett nytt Maven Archetype projekt med quickstart-arketypen.
2. Skapa konfigurationer (Configurations) för att köra både servern och klienten - det finns main i båda filerna. 
3. Kör programmet via intellij IDEA.
4. Använd webbläsaren eller Postman för att interagera med servicen.
